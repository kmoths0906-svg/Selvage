# Selvage

A fiber-composition search engine for clothing — search only by what a garment is actually made of (100% cotton, 100% linen, natural blends only, no polyester, etc.), without ever having to open a materials tab.

## Repo layout

- `supabase/migrations/` — database schema, applied automatically to the connected Supabase project on merge to `main`
- `db/schema.sql` — same schema, kept as a readable reference copy

## Status

MVP in progress. See the architecture doc for the full system design and the two-week build plan.
